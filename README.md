# TBankInvestESP32

#[YOUTUBE DEMONSTRATION](https://www.youtube.com/shorts/kVmrspDRLEU)

Прошивка для платы **Waveshare ESP32-C6-LCD-1.47** (ESP32-C6-WROOM-1, 4 МБ флеша, LCD
172×320 на контроллере ST7789, интерфейс SPI2). Устройство подключается к Wi-Fi,
синхронизирует время по SNTP, определяет `figi` заданного тикера (по умолчанию — `SiU6`,
фьючерс MOEX USD/RUB) через API Т-Банк Инвестиции и затем непрерывно опрашивает последнюю
цену и часовые свечи, отображая их на экране с помощью LVGL.

Собирается через PlatformIO на фреймворке `espidf`.

## Возможности

- Отображение текущей цены инструмента и статуса подключения на LCD.
- График котировок: свечи или линия — настраивается.
- Гибкий период свечей: минута, час, день, неделя.
- Отслеживание произвольного тикера MOEX (акции, фьючерсы) — тикер резолвится в `figi`
  автоматически при старте.
- TLS-соединение с API проверяется по встроенному российскому доверенному корневому
  сертификату (Russian Trusted Root CA).

## Требования

- Плата Waveshare ESP32-C6-LCD-1.47.
- [PlatformIO](https://platformio.org/) (CLI или расширение для VS Code).
- Токен T-Bank Invest API (выпускается в личном кабинете брокера).
- Сеть Wi-Fi с доступом в интернет.

## Быстрый старт

```bash
git clone git@github.com:alexex1993/TBankInvestESP32.git
cd TBankInvestESP32
cp example.env .env      # и заполнить реальными значениями, см. ниже
pio run -t upload -t monitor
```

## Сборка, прошивка, монитор

Все команды выполняются из корня репозитория (имя окружения — `esp32-c6-lcd-1_47`):

```bash
pio run                        # сборка
pio run -t upload              # сборка + прошивка
pio run -t upload -t monitor   # прошивка и открытие серийного монитора
pio device monitor             # только серийный монитор (115200 бод)
pio run -t clean               # очистка артефактов сборки
```

Тестов и линтера в проекте нет (`test/` содержит только заглушку от PlatformIO).

## Настройка секретов (`.env`)

Перед каждой сборкой автоматически запускается `tools/gen_secrets.py` (подключён через
`extra_scripts` в `platformio.ini`). Он читает `.env` в корне репозитория и генерирует
`src/secrets.h` с C-макросами. Файлы `.env` и `src/secrets.h` в `.gitignore` — коммитить их
нельзя. Полный список переменных с комментариями — в `example.env`.

| Переменная         | Обязательна | По умолчанию | Назначение                                                                 |
|--------------------|:-----------:|---------------|----------------------------------------------------------------------------|
| `TBANK_TOKEN`      | да          | —             | Токен T-Bank Invest API                                                    |
| `WIFI_SSID`        | да          | —             | Имя точки доступа Wi-Fi                                                    |
| `WIFI_PASSWORD`    | да          | —             | Пароль точки доступа Wi-Fi                                                 |
| `CHART_TYPE`       | нет         | `candles`     | Тип графика: `candles` или `line`                                          |
| `CANDLE_INTERVAL`  | нет         | `minute`      | Размер бакета свечи: `minute`, `hour`, `day`, `week`                       |
| `INSTRUMENT_TICKER`| нет         | `SiU6`        | Тикер MOEX для отслеживания (резолвится в `figi` при старте)               |

Если обязательная переменная не задана, сборка падает с понятным сообщением об ошибке.

## Архитектура

Последовательность запуска (`src/main.c`):

1. `nvs_flash_init()`.
2. `display_init()` — инициализация SPI2, панели ST7789 через `esp_lcd` и LVGL.
3. `ui_init(disp)` — статичная разметка экрана (заголовок, цена, статус, график).
4. `wifi_manager_connect_blocking()` — блокирующее подключение к Wi-Fi.
5. Синхронизация времени по SNTP (best-effort).
6. `market_task_start()` — запуск фоновой FreeRTOS-задачи со всей рабочей логикой.

**Фоновая задача** (`src/market_task.c`) один раз при старте резолвит тикер в `figi`
(повторяя попытку каждые 10 с при неудаче), затем в бесконечном цикле опрашивает
последнюю цену и свечи с заданными интервалами (`src/app_config.h`) и обновляет UI.

**LVGL** однопоточен — все вызовы `lv_*` извне задачи LVGL обязаны быть обёрнуты в
`display_lvgl_lock()`/`display_lvgl_unlock()` (`src/display.c`).

**Клиент T-Bank API** (`src/tbank_api.c`, `src/http_client_util.c`) работает напрямую по
REST/JSON-шлюзу через `esp_http_client` (без gRPC/SDK на устройстве), проверяя сертификат
сервера по встроенному российскому доверенному корневому сертификату. Общий справочник по
API — `tbank-invest-api-guide.md` в корне репозитория.

Подробности по железу, партициям и параметрам сборки — в `CLAUDE.md`.

## Зависимости

Управляются через ESP-IDF Component Manager (`src/idf_component.yml`), а не реестр
библиотек PlatformIO:

- `lvgl/lvgl ^9.2`
- `espressif/cjson ^1.7`

`managed_components/` и `dependencies.lock` в `.gitignore` и не редактируются вручную.
